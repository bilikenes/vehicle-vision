# Vehicle Vision

Vehicle Vision, araç görüntülerini yapay zekâ ile analiz eden bir web deneyimi için geliştirilen projedir. Next.js frontend foundation'ı ve ilk iki homepage section için tasarım/etkileşim spesifikasyonu hazırdır.

## Mevcut durum

- Dokümantasyon omurgası kuruldu.
- İlk iki homepage section için tasarım kararları kilitli durumda.
- Next.js, React, TypeScript ve App Router foundation'ı oluşturuldu.
- Global renk, spacing ve typography token'ları tanımlandı.
- Hero videosu ve display font merkezi, geçici kaynaklar üzerinden bağlandı.
- Tipografi içindeki final wheel asset'i gelecek iş olarak tanımlı.
- Referans sitelerin yerel kaynak dizinleri doğrulandı: `D:\web-sites\waabi`, `D:\web-sites\eclipse`, `D:\web-sites\daylight`.
- İlk iki section için aşamalı implementation planı hazırlandı.

## Geliştirme

```powershell
npm install
npm run dev
```

Kalite kontrolleri:

```powershell
npm run lint
npm run typecheck
npm run build
```

Güncel çalışma durumu için [`docs/PROJECT_STATUS.md`](docs/PROJECT_STATUS.md), yapılacak işler için [`docs/ROADMAP.md`](docs/ROADMAP.md), ilk iki section'ın uygulama sırası için [`docs/IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md), proje içi dosya haritası için [`docs/CODEBASE_MAP.md`](docs/CODEBASE_MAP.md) kullanılmalıdır.
